Tahqiq Muhammad Fu'ad 'Abd al-Baqi (تحقيق محمد فؤاد عبد الباقي)

Buka di Internet Archive ↗

Piawaian penomboran antarabangsa terunggul bagi Sahih Muslim yang disusun oleh Syeikh Muhammad Fu'ad 'Abd al-Baqi pada tahun 1374 H / 1955 M melalui percetakan 'Isa al-Babi al-Halabi (kemudian diulang cetak oleh Dar Ihya' al-Turath al-'Arabi di Beirut). 💻 3. Muat Turun Berkelompok Melalui Baris Perintah (CLI)

Gunakan skrip Python terbina dalam untuk memuat turun jilid tambahan ke komputer anda secara automatik.

# 1. Lihat senarai jilid yang tersedia bagi Edisi Dar al-Ta'sil python scripts/download_scanned_editions.py --edition dar-al-taseel # 2. Muat turun jilid tertentu (contohnya Jilid 2) python scripts/download_scanned_editions.py --edition dar-al-taseel --volume 2 # 3. Muat turun kesemua 8 jilid Edisi Dar al-Ta'sil sekaligus python scripts/download_scanned_editions.py --edition dar-al-taseel --all # 4. Muat turun naskhah terjemahan dwibahasa Darussalam (Jilid 1) python scripts/download_scanned_editions.py --edition darussalam-bilingual --volume 1
