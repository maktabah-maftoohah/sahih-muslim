# Naskhah Cetakan Muktabar & Dokumen Digital Sahih Muslim

> 🌐 **Versi Laman Web Interaktif**: Sila layari [Halaman Dokumen & Naskhah Cetakan Sahih Muslim](https://maktabah-maftoohah.github.io/sahih-muslim/docs/) untuk paparan antara muka visual berjadual berserta butang muat turun segera.

> **Koleksi:** Sahih Muslim (*Al-Musnad al-Sahih al-Mukhtasar min al-Sunan bi-Naql al-'Adl 'an al-'Adl ila Rasulillah SAW*)  
> **Penyusun:** Al-Imam Abu al-Husayn Muslim ibn al-Hajjaj al-Qushayri an-Naysaburi (204–261 H)

Dokumen ini merekodkan naskhah cetakan primer (*primary printed editions*), manuskrip rujukan, serta format fail dokumen (PDF, EPUB) yang disimpan dan diindeks dalam repositori ini.

---

## 1. Format Dokumen yang Disimpan Terus dalam Repositori (`documents/`)

Bagi memudahkan pembacaan luar talian dan akses segera tanpa memerlukan capaian internet, repositori ini menyertakan fail dokumen digital berikut:

### A. Sahih Muslim — EPUB 3.0 Lengkap
* **Fail:** [`documents/sahih-muslim.epub`](../documents/sahih-muslim.epub)
* **Saiz:** ~3.7 MB
* **Ciri-Ciri:**
  - Merangkumi kesemua **57 Kitab** (termasuk Muqaddimah) dan **7,563 Hadis**.
  - Teks Arab berbaris penuh (*tashkeel*), terjemahan Bahasa Melayu, dan terjemahan Bahasa Inggeris (Nasiruddin al-Khattab).
  - Susun atur reflowable standard EPUB 3.0 yang serasi dengan Apple Books, Calibre, Kobo, Moon+ Reader, dan pelbagai aplikasi pembaca e-buku Android/iOS.

### B. Edisi Dar al-Ta'sil — Jilid 1 (Tahqiq Manuskrip Muktabar 1435 H)
* **Fail:** [`documents/muslim_taseel_01.pdf`](../documents/muslim_taseel_01.pdf)
* **Saiz:** ~12.7 MB
* **Penerangan:** Imbasan dokumen resolusi tinggi Jilid Pertama daripada edisi tahqiq moden terulung oleh Dar al-Ta'sil (Kaherah), merangkumi Muqaddimah al-Imam Muslim dan Kitab al-Iman berpandukan naskhah manuskrip asal.

## 3. Cara Memuat Turun Jilid Tambahan Menggunakan CLI

Skrip [scripts/download_scanned_editions.py](../scripts/download_scanned_editions.py) disediakan untuk memuat turun mana-mana jilid secara automatik:

```bash
# Lihat senarai jilid yang tersedia
python scripts/download_scanned_editions.py --edition dar-al-taseel

# Muat turun jilid tertentu (contohnya Jilid 2)
python scripts/download_scanned_editions.py --edition dar-al-taseel --volume 2

# Muat turun kesemua 8 jilid Edisi Dar al-Ta'sil
python scripts/download_scanned_editions.py --edition dar-al-taseel --all

# Muat turun edisi dwibahasa Darussalam (contohnya Jilid 1)
python scripts/download_scanned_editions.py --edition darussalam-bilingual --volume 1
```
